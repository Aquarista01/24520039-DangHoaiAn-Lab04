# Task Decomposition

1. Create the project configuration, contract and demo fixture.
2. Write and run failing automated contract tests.
3. Implement the lazy route, Suspense and loading semantics.
4. Refactor shared skeleton geometry and responsive styling.
5. Verify production chunks, layout shifts and accessibility.
6. Run final checks and commit verified changes.

## Suggested Commit Groups

- Setup and contract.
- Failing tests.
- Lazy route, Suspense and loading semantics.
- Skeleton geometry, focus styling and verification fixes.

The groups are implementation choices.
They do not define a lecturer-mandated commit count.
